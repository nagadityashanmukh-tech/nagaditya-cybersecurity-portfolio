# Nagaditya Shanmukh — Cinematic Cybersecurity Portfolio

## IMPORTANT: How to open
1. Download the ZIP file and wait for the download to finish.
2. Right-click the ZIP and choose **Extract All** (Windows), or double-click it (Mac).
3. Open the extracted folder `Nagaditya_Hacker_Portfolio_SUPER`.
4. Double-click `index.html`.
5. If it appears stuck, refresh once or open `index.html` in Chrome or Edge.

Do not try to open `index.html` from inside the ZIP preview. Extract the complete folder first.

## Included
- Dark hacker theme, matrix background, cinematic startup sequences and typewriter effects.
- Animated profile photo with rotating neon rings, scanning laser and floating particles.
- Interactive project details, certificates, posts and report links.
- Responsive layout and reduced-motion accessibility support.
